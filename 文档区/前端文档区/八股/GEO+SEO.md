# GEO + SEO

## SEO

Search Engine Optimization，中文名叫搜索引擎优化，做好SEO，可以实现，当用户通过搜索关键字词查找网站时，让我们的网站可以在更靠前的部分被搜到，获得好的排名和流量从而提高网站知名度。

### 比较常见的SEO方案

#### 1. TDK优化

Title、MetaDescription、Meta keywords。对这三个信息的提炼是网站SEO的重要环节。
但metakeywords现在已经被很多主流搜索引擎给移除了。

1. title
就是网站的tab页上那个简短的名字，相当于网站的名片，会直接显示在搜索结果中。

2. meta标签-网站信息
是网页head区的辅助性标签，通过配置一些参数用以描述页面属性。
目前几乎所有搜索引擎都用网上机器人自动查找meta值来给网页分类
有 name 和 http-equiv 两个属性可以配置：
- name： 配置项+对应内容
- http-equiv：http的文件头作用，它可以向浏览器传回一些有用的信息，以帮助正确和精确地显示网页内容。
``` html
<meta name="keywords" content="keywords关键词，目前不再使用">
<meta name="description" content="非常重要，搜索引擎会把description的描述显示在搜索结果中">
<meta name="format-detection" content="telephone=no">
<meta name="author" content="cece">
<Meta name="Robots" Content="Nofollow">
/** 
all：文件将被检索，且页面上的链接可以被查询；  
none：文件将不被检索，且页面上的链接不可以被查询；(和 "noindex, no follow" 起相同作用)  
index：文件将被检索；（让robot/spider登录）  
follow：页面上的链接可以被查询；  
noindex：文件将不被检索，但页面上的链接可以被查询；(不让robot/spider登录)  
nofollow：文件将不被检索，页面上的链接可以被查询。(不让robot/spider顺着此页的连接往下探找)
*/
<meta name="theme-color" content="#4285f4" />

<meta http-equiv="参数"content="参数变量值">；
<meta http-equiv="refresh" content="定义文档自动刷新的时间间隔（下面content中的2是指停留2秒钟后自动刷新到URL网址）。这个属性值慎重使用，因为它会使得页面不受用户控制；">

<meta http-equiv="Set-Cookie"content="如果网页过期，那么存盘的cookie将被删除；">
```

3. Open Graph协议标签
这个是配合meta标签来使用，当网页支持OG标签，那么网站分享卡片的分享内容样式会更加丰富一点

#### 2. 网站质量

如果一个网站性能不好，会降低用户留存率，搜索引擎会认为该网站对用户不友好，也会降低排名。

#### 3. 网页301 重定向 [计算机网络相关]

集中域名权重：比如输入 www.openai.com重定向到openai.com,其实就是把前者的权重转移到了后者，可以增加后者域名的权重，避免重复收录。
优化用户体验：类似于上一条说的那样，不管是输入ww.openai.com还是openai.com其实都会定向得到最终想要的网址，可以优化用户体验。

#### 4. 尽量使用https。

谷歌曾发公告表示，使用安全加密协议（HTTPS），是搜索引擎排名的一项参考因素。
所以，在域名相同情况下，HTTPS站点比HTTP站点，能获得更好的排名。

#### 5. SSR服务端渲染

服务端渲染是指，客户端向服务端发起请求后，服务端执行好js，生成html直接返回给客户端，客户端便可以获取到完整的页面内容。
我常用的就是next.js
而且也能优化首屏加载速度，优化用户体验


## GEO

Generative Engine Optimization，翻译过来叫"生成式引擎优化"。

与SEO类似，但它不是搜索引擎的排名了，而是通过询问AI后，AI给出的答案里会不会提到我们的网站。
SEO 是让搜索引擎找到你并把你排在前面，GEO 是让 AI 在回答问题时愿意把你的内容当参考。

要了解GEO，便要了解ai是如何调内容的
而AI生成回答时，会在两个时间段参考内容：1. 训练前 2.回答时。

1. 训练前：
大模型在训练前的大部分都是从互联网上爬取，但是过程中还会从原始数据筛选到高质量数据。
我们要保证我们的数据信息不会在这个过程中被筛选出去。我们要避免我们网站的内容质量低下，比如说语句是否通顺，标题段落是否清晰.....

2. 回答时：
训练数据会过时，所以在回答时，往往会使用RAG来得到最新信息，而在检索过程中，我们能否被AI在答案里被提到，就卡在排名打分和Top-k的步骤
会从三个维度打分
- 语义相关性：内容和用户提问的问题，转换成向量后相似度高不高，
- 信息密度：同样的长度，我们传达的信息是否比别人多
- 可引用性：能否让模型尽量少的理解上下文就可以直接得到回答

### GEO手段方法

1. 内容直接，只给出定义，简明扼要
2. 结构要清晰，分级标题等
3. 有对比，信息也要有边界
4. 信息有权威性
5. 可以有总结性的结论。
